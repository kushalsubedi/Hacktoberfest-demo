# AI Beyond the Prompt — Hacktoberfest 2026

Kushal Subedi · 6 October 2026

The workshop in three parts, in order:

1. **QuizBot** — tools / function calling: the AI pulls real trivia from the internet and keeps score.
2. **NotesBot** — RAG: the AI answers questions from a markdown file it has never seen.
3. **Knowledge Base (MemBot)** — memory: the AI forgets your name on restart, until we give it a knowledge base — then we add the same trick to both projects.
